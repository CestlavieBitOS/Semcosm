# Semcosm

Semcosm uses a minimal top-level layout to keep code and documentation separated.

## Top-Level Structure

- `src/`: source code, scripts, modules, and runtime assets
- `doc/`: product docs, architecture notes, specs, and project records

## Directory Rule

Only keep `src/` and `doc/` as primary project directories at the repository root unless there is a clear reason to expand the layout later.
